getAnalysisResults(*analysis_types: AnalysisResultsType) → AnalysisResults#

Returns an AnalysisResults dict keyed by AnalysisResultsType.

If analysis_types are passed, only those result tables are fetched. If none are passed, all enabled analysis types are returned. Each table is a ResultsTable (pandas DataFrame) with Excel-equivalent columns.
